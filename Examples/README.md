# Examples Workspace

Examples are small programs for learning one API, concept, source module, kernel, or algorithm. They are not full research experiments.

Organize mature content progressively as `01_basics/`, `02_concepts/`, and `03_source_study/` within the appropriate language directory. Python environments are managed only by per-simulator Conda files. Compiled examples are managed by Xmake and write generated output to the root `build/examples/` directory.

No example targets or fake source files are created during repository initialization.
