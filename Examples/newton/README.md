# Newton Examples

Status: Planned

## Purpose

Hold minimal Python programs for learning Newton's public API and GPU-oriented simulation workflow.

## Environment

Use the `newton` Conda environment in `environment.yml`. It records the upstream Python 3.10+ requirement. GPU, Warp, and simulator dependencies are intentionally deferred until a concrete example is implemented.

## Directory Structure

- `python/`: Python API and source-study programs.
- Add `01_basics/`, `02_concepts/`, and `03_source_study/` only as examples are written.

## Build / Run

Create the Conda environment, add only the dependencies required by the example, and document the exact run command with that example. Xmake does not manage Python.
