# Experiments

Experiments answer technical questions through reproducible comparisons or measurements. They differ from Examples, which demonstrate one API or concept.

Start from `_template/`. Keep the question, environment, configuration, method, metrics, analysis, and conclusion explicit. Raw outputs, caches, temporary data, large logs, videos, checkpoints, and large meshes must not be committed. Small Markdown or CSV summaries may be kept under `results/summary/`.
